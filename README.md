# Práctica MySQL — Ingeniería Inversa y Consultas DQL

## Descripción

Desarrollo de una actividad práctica de bases de datos relacionales utilizando MySQL, enfocada en la interpretación de estructuras, la representación de relaciones entre tablas y la resolución de consultas SQL mediante el lenguaje DQL (*Data Query Language*).

## Bases de datos trabajadas

| # | Base de datos | Descripción |
|---|---|---|
| 1 | HelpDesk Pro | Sistema de gestión de tickets y soporte técnico. |
| 2 | AssetControl | Sistema de administración y control de activos. |
| 3 | CompraFácil | Sistema de gestión de compras. |
| 4 | TalentTrack | Sistema de gestión de talento humano. |
| 5 | SpaceBook | Sistema de reservas de espacios. |

## Contenido de la entrega

El archivo `ENTREGA_FINAL_MYSQL_5_BASES.zip` contiene:

- 5 scripts SQL con la estructura y los datos de las bases de datos.
- 5 diagramas relacionales que representan tablas, claves primarias, claves foráneas y relaciones.
- 100 consultas DQL resueltas, distribuidas en 20 ejercicios por base de datos.
- Diagramas disponibles en formato PDF y PNG.

## Conceptos aplicados

- Modelado de bases de datos relacionales.
- Ingeniería inversa a partir de estructuras SQL.
- Claves primarias (PK) y foráneas (FK).
- Consultas `SELECT`, `WHERE` y `ORDER BY`.
- Relaciones mediante `INNER JOIN` y `LEFT JOIN`.
- Agrupaciones con `GROUP BY` y `HAVING`.
- Funciones de agregación: `COUNT`, `SUM`, `AVG`, `MIN` y `MAX`.
- Subconsultas SQL.

## Herramientas y tecnologías

- MySQL
- SQL / DQL
- Diagramas entidad-relación
- Git y GitHub

## Objetivo

Comprender la estructura de diferentes bases de datos empresariales, identificar sus relaciones y aplicar consultas SQL para obtener información relevante a partir de sus registros.
